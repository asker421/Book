# V3 PROMPT PACK — ИНСТРУКЦИЯ

Source commit: `17f48f3e1dc0dc03fba362de8435644672b0d28d`.

Комплект предназначен для полного последовательного rewrite V3 романа «Красная будка» и содержит **40 индивидуальных prompts: 35 глав + 5 интерлюдий**.

## Как использовать
1. Пользователь явно называет ОДИН эпизод.
2. Открыть его файл из `prompts_v3/episodes/`.
3. Восстановить состояние по Git, канонам, ledgers, `V3_PROGRESS.md` и worklog.
4. Выполнить только этот цикл: **написание → полный аудит → хирургические исправления → повторный аудит до проверяемой готовности → Git/worklog/progress → полный показ текста → STOP**.
5. Следующий эпизод запрещён до новой явной команды пользователя.
6. Статус `одобрена пользователем` ставится только после явного одобрения.

## Источник истины
Приоритет определяет `MANIFEST.md`; финальная механика — `FINAL_CANON_OVERRIDE.md`.
Embedded brief в prompt не заменяет чтение актуальных источников.
Если source documents изменились после `17f48f3e1dc0dc03fba362de8435644672b0d28d`, individual prompt обязан быть revalidated.

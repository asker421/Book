# Рабочий промпт полного аудита главы — V4

## Статус

Этот файл задаёт **активный audit engine V4** для романа «Красная будка».

Художественный source of truth: `chapters_v4/`.  
Активная структура: **30 глав + 4 интерлюдии**.

Старые V3-процедуры, ссылки на главы 31–35, Интерлюдию V, Долгий дом, Резерв-19, Реестр/Предел-6 и автономный резерв не применяются к V4.

Перед аудитом обязательно открыть:
- `MANIFEST.md`;
- `V4_AUTHORING_RULES.md`;
- `V4_NAMING_CANON.md`;
- `FINAL_CANON_OVERRIDE.md`;
- `MASTER_ROMAN_AUDIT.md`;
- `MAXIMUM_CAUTION_AUDIT_PROTOCOL.md`;
- текущую главу целиком;
- предыдущую и следующую активные главы;
- все релевантные специализированные canon/ledger-файлы.

---

# 1. COLD START

Каждый новый audit run начинается со статуса:

**NOT VERIFIED**

Нельзя наследовать старый PASS, READY, worklog или результат другого агента как доказательство.

Если проверяемый художественный blob или релевантный канон изменился во время работы — перечитать новый blob.

---

# 2. LINE-BY-LINE / REPLICA-BY-REPLICA

Проверять каждую единицу текста:

- повествовательное предложение;
- реплику;
- физическое действие;
- переход позиции;
- новый факт;
- вывод персонажа;
- смену знания;
- смену отношения;
- предмет;
- технический термин.

Для каждого задавать:
1. физически возможно?
2. персонаж может это видеть/слышать?
3. персонаж имеет право это знать?
4. реплика соответствует его голосу и состоянию?
5. действие имеет мотивацию?
6. не повторяет ли автор уже показанный вывод?
7. не создаёт ли строка новый канон случайно?

---

# 3. CHAPTER CONTRACT

Проверить по `CHAPTER_BY_CHAPTER_CANON.md`:

- функция главы;
- обязательные события;
- обязательный delta;
- запреты;
- exit state.

Для 29–30 действует только активный V4 contract, а не исторические V3-разделы.

---

# 4. KNOWLEDGE / REVEAL

Проверить:

- источник каждого важного знания;
- факт vs гипотеза;
- отсутствие случайного знания;
- отсутствие backstage-информации;
- корректный момент раскрытия термина.

Активные V4 границы:
- RETRO-1 — впервые в главе 29;
- мужчина 2014 = Асгар — физически подтверждается в главе 30;
- историческая адресация как принцип — глава 27;
- конкретная source-технология общего объёма — глава 29;
- 2039 не обсуждается как финальный план до завершения сцены 2014;
- конкретное следствие однозначности пассажирской записи — только после отказа 2039 в главе 30.

---

# 5. PHYSICS / CAUSALITY

Проверить:

- одна мировая линия;
- нет параллельных ветвей;
- RETRO-1 возвращает себя;
- полная сверка массы только после закрытия двери;
- Асгар — незапланированная внешняя нагрузка;
- пассажирская запись одна и не закрывается промежуточными выходами;
- операторы не выбирают даты;
- сервисная линия Мирены не является свободной связью во времени;
- исторический доступ не является replay;
- общий объём ограничен восстановимой внешней геометрией;
- каждый новый исторический вход должен уже существовать в единственной истории.

---

# 6. STAGING / MICRO-STAGING

Фиксировать:
- позицию Асгара;
- состояние двери;
- положение трубки и длину шнура;
- линии видимости;
- положение перегородок;
- последовательность шагов;
- наблюдаемость походки и частей тела.

Обязательные pair-check:
- **глава 1 ↔ глава 30 / 2014**;
- **глава 8 ↔ глава 30 / 2039**.

---

# 7. TIME / BODY / INVENTORY

Проверить:
- субъективно прожитое время;
- тело;
- сторону травмы;
- шрамы;
- одежду;
- переносимые предметы;
- приобретённые навыки.

Финальный continuity-ориентир V4: около **827–828 субъективных дней**, примерно **2 года 3 месяца**.

Перед финальным доступом к 2014:
- сумка остаётся у источника;
- палка остаётся у источника;
- куртка остаётся у источника;
- чёрная медицинская лента скрыта рукавом;
- на Асгаре обычная тёмная одежда.

---

# 8. LANGUAGE / COMMUNICATION

Для каждого разговора указать реальный канал:

- общий язык;
- переводчик;
- историческая языковая модель;
- локальная система;
- сервисный телефон;
- внешний аудиомост.

Запрещено:
- переносить голос Мирены в пространство без отдельного канала;
- делать RETRO-1 универсальным переводчиком;
- давать персонажу слышать через закрытую перегородку без связи;
- автоматически давать будущим людям русский.

---

# 9. MOTIVATION / ANTI-IDIOT

Для каждого крупного решения:
- цель;
- новый факт;
- риск;
- альтернатива;
- почему не выбрана более простая;
- можно ли отказаться.

Особо:
- уход из 2039;
- уход из Ар;
- решение продолжить в 87116;
- продолжение после 22 месяцев одиночества;
- молчание в 2014;
- требование проверить 20/24.08.2014 перед 2039.

---

# 10. HUMAN REACTION / VOICE

Проверить:
- реакцию на невозможное;
- профессиональную реакцию без преждевременного принятия;
- различимость голосов;
- отсутствие одинаковой рубленой речи;
- отсутствие «все говорят слишком умно»;
- отсутствие идеальных лекционных ответов в момент шока.

---

# 11. ASGAR FLAW / RELATIONSHIPS

Проверить, что Асгар:
- способен давить;
- повторяет вопрос, когда не принимает ответ;
- иногда рационализирует желание;
- способен быть несправедливым;
- не всегда первым замечает моральную цену;
- не превращается в идеального морального арбитра.

Разрыв с Миреной после главы 22 должен иметь след.

---

# 12. PROSE / TICS / READER EXPERIENCE

Проверить:
- нет ли сценарной лесенки;
- нет ли псевдоударных коротких абзацев;
- нет ли двойного показывания;
- нет ли авторского объяснения эмоции;
- нет ли туристической камеры;
- нет ли диалога как API;
- нет ли пересказа важного разговора;
- нет ли текста, который доказывает читателю собственную правоту;
- после каждого описательного абзаца читатель дальше внутри момента, а не только лучше информирован.

---

# 13. V4 FINAL GATES

## Глава 29
Проверить:
- источник = искусственный узел Солнечной системы;
- универсального «года сейчас» нет;
- Мирена недоступна;
- RETRO-1 впервые назван;
- конкретная архитектура причинно замкнута, физика науки — нет;
- Асгар не обсуждает 2039 заранее;
- immediate goal = 16.08.2014;
- исторический доступ физический, ограниченный и не свободный.

## Глава 30
Проверить:
- старший Асгар физически может вмешаться;
- молчание свободно;
- молодой Асгар входит сам и закрывает дверь сам;
- сначала проверяются 20.08.2014 и 24.08.2014;
- потом 24.08.2039;
- Катя и Асгар не получают невозможный голос через стекло;
- постоянный выход отказывает по однозначности пассажирской записи;
- это не запрет «двум Асгарам быть одновременно»;
- Асгар требует альтернативы/перепроверку;
- RETRO-1 завершает возврат;
- пассажирская запись остаётся открытой;
- нет sequel-hook;
- финальная строка не меняется.

---

# 14. VERDICT

Для каждой найденной проблемы указывать:
- severity: CRITICAL / MAJOR / MINOR;
- файл;
- точное место;
- нарушенный canon;
- почему это нарушение;
- минимальный способ исправления.

Глава получает PASS только при:
- CRITICAL = 0;
- MAJOR = 0.

Для финального VERIFIED/READY применять требования `MAXIMUM_CAUTION_AUDIT_PROTOCOL.md`: два независимых полных чистых прохода на неизменённом blob.

# worklogs_v3

Этот каталог хранит долговечные журналы rewrite/audit по ОДНОМУ эпизоду.

Каждый worklog обязан содержать:
- эпизод и пути;
- source commit и фактически использованные источники;
- текущий статус;
- указания пользователя;
- историю каждого audit pass;
- конкретные дефекты и нарушенные требования;
- исправления;
- результаты recheck;
- оставшиеся blockers;
- итоговое выходное состояние;
- явный факт пользовательского одобрения — только если он получен.

Разрешённые статусы:
`в работе` / `аудит и исправления` / `заблокирована` / `проверена, ожидает решения пользователя` / `одобрена пользователем`.

Не стирать историю pass’ов.
Не логировать внутренний chain-of-thought; логировать только проверяемые результаты.

# EPOCH CAPABILITY CANON — «Красная будка»

Этот файл фиксирует технологический потолок и запреты каждой крупной эпохи актуального корпуса `chapters_v3/`. `chapters_v2/` остаётся историческим baseline/source material и не является действующим художественным источником истины.

Цель: не позволять будущему становиться магией. Чем дальше эпоха, тем мощнее могут быть локальные технологии, но **ни одна эпоха не получает автоматически возможности, которой в каноне у неё нет**.

Главный принцип:

> высокая технологичность ≠ всеведение ≠ свободное путешествие во времени ≠ понимание RETRO-1.

# 1. ОБЩИЕ ИНВАРИАНТЫ ДЛЯ ВСЕХ ЭПОХ

Ни одна промежуточная цивилизация до линии источника не может:

- выбрать следующую дату RETRO-1;
- приказать модулю вернуться в 2014;
- создать новое историческое окно RETRO-1;
- прочитать всю будущую траекторию модуля;
- узнать финальную причинную петлю только из одного измерения;
- автоматически отделить Асгара от пассажирской записи;
- считать красную форму доказательством происхождения технологии;
- превратить локальную геометрическую технологию в свободную машину времени без отдельного канонического основания.

Локальная цивилизация может быть намного технологичнее XXI века и всё равно не знать физику RETRO-1.

# 19. CAPABILITY TEST

Для любого технологического действия спросить:

1. Кто именно это делает?
2. Какая эпоха?
3. Был ли такой класс технологии уже установлен?
4. Если технология новая — есть ли сцена, которая её вводит?
5. Не решает ли она случайно более сложную проблему, чем должна?
6. Если эта эпоха умеет X, почему она не решила RETRO-1 полностью?
7. Не превращает ли локальная геометрия свободное путешествие во времени?
8. Не получил ли персонаж знание только потому, что «они очень далеко в будущем»?
9. Есть ли физическая/энергетическая/информационная цена действия?
10. Не возвращает ли сцена технологию удалённой эпохи?

Если ответ сводится к «в будущем такое наверняка умеют», действие неканонично до отдельного закрепления.

# ETHICAL CAPABILITY RULE

Технологическое развитие эпохи не означает моральной однородности людей.

Высокая способность цивилизации:
- не делает всех доброжелательными;
- не отменяет карьеру, страх, власть, статус и конфликт ресурсов;
- не создаёт автоматический консенсус вокруг Асгара;
- не делает отказ от помощи признаком технологической отсталости.

Но и обратное запрещено:
каждая будущая эпоха не обязана производить тирана, культ или злого чиновника.

Ар может иметь Вардана.
87116 может обойтись без персонального злодея.
Резерв-19 может иметь острый этический спор без злодея вообще.

# ETHICAL / SOCIAL CAPABILITY RULE

Технологическое развитие эпохи не означает моральной однородности.

Высокая технологичность не делает всех доброжелательными, не отменяет карьеру, страх, власть, статус и конфликт ресурсов и не создаёт автоматический консенсус вокруг Асгара.

Обратное тоже запрещено: каждая будущая эпоха не обязана производить тирана, культ или злого чиновника.
